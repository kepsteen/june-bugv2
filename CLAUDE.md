# Project-Specific Instructions

## Package Manager

This project uses **pnpm** as the package manager. Always use `pnpm` commands instead of `npm`:

- `pnpm install` - Install dependencies
- `pnpm run <script>` - Run package scripts
- `pnpm add <package>` - Add new dependencies
- `pnpm remove <package>` - Remove dependencies

## Commands

- `pnpm run type-check` - Run TypeScript type checking
- `pnpm run test:run` - Run test suite
- `pnpm run dev` - Start development servers
- `pnpm run db:generate` - Generate database migrations
- `pnpm run db:migrate` - Run database migrations
