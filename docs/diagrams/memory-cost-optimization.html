Memory Extraction — Cost Optimization (Proposed)

Today every autosave triggers a full LLM extraction (5–15 calls per writing session). Because memories are long-term context (hours of lag is acceptable), the fix is a nightly batch sweep: stop extracting on save entirely, and once a day extract only the entries whose plain_text changed since their last extraction (guarded by a content hash). A cron job triggers it by running a repo script — no HTTP endpoint, no secret, no in-process timers, no queue.
